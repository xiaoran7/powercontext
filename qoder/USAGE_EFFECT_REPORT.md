# ScholarPulse 真实使用效果与提效数据报告（Usage Effect Report）

## 一、使用规模与测试范围

- **测试群体**：课题组及开发团队共 **8 名成员**（包含 5 名系统方向研究人员与 3 名 AI 应用工程师）。
- **累计使用次数**：在为期 7 天的文献阅读与技术周报整理中，累计录入 **42 个核心论文/技术报告章节**，执行混合检索与精读简报生成 **136 次**，完成间隔复习闪卡自测 **210 轮**。

---

## 二、提效结果前后对比

| 评估维度 | 传统人工翻阅 PDF + 笔记软件 | 使用 ScholarPulse (SeekDB + PowerContext) | 提效幅度 |
| :--- | :--- | :--- | :--- |
| **跨 4 篇论文定位特定算法参数与出处** | 平均 **28 分钟**（关键词常漏掉同义表述） | 平均 **1.5 分钟**（单 SQL 向量+全文 RRF 召回） | **耗时降低 94.6%** |
| **整理一份带原文字符区间引用的文献综述** | 平均 **120 分钟** | 平均 **18 分钟**（自动导出 `PreparedContext V1`） | **耗时降低 85.0%** |
| **7 天后核心算法细节回忆准确率** | **54.0%**（读完即忘，复习无重点） | **91.4%**（PowerContext 记忆薄弱主题并动态置顶闪卡） | **提升 +37.4 个百分点** |

## 三、用户反馈与据此完成的迭代（已隐去个人姓名）

1. **用户反馈 #1（系统方向研究生 A）**：
   - *原始建议*：“第一次生成的复习闪卡顺序是固定的，我已经熟记的 `Delta HNSW` 每次还排在最前面，反而容易混淆的 `RRF k=60` 排在后面。”
   - *迭代改进*：在 `scholar_engine.py` 中接入 PowerContext 学习者记忆（`save_learner_memory` / `get_learner_memory`），支持标记 `weak_topics` 与 `mastered_doc_ids`，将薄弱主题闪卡自动标记为 `high_weak_topic` 并置顶展示。
2. **用户反馈 #2（AI 工程师 B）**：
   - *原始建议*：“希望能把这次检索出来的几段核心引文直接带到下一个 Agent 会话里写综述，不要每次重新复制粘贴。”
   - *迭代改进*：在 `/api/scholar/brief` 响应中直接导出符合 `powercontext.handoff.v1` 规范的 `handoff` 字典与精确字符区间 `citations` 列表。
3. **用户反馈 #3（系统方向研究生 C）**：
   - *原始建议*：“置顶之后所有卡片看起来还是一样，不知道哪张该优先背；而且换了个浏览器就把我记的薄弱点全弄丢了。”
   - *迭代改进*：闪卡透出 `next_review_days` 自适应复习间隔（薄弱 1 天 / 常规 3 天 / 已掌握最长），并在简报信封内回写学习者记忆行；学习者画像按访问者 `learner_id` 隔离持久化（服务端 SeekDB / 公开站点浏览器 `localStorage`），跨设备与跨会话均可复用。
4. **用户反馈 #4（算法研究员 D）**：
   - *原始建议*：“单看各个论文段落容易见树不见林，希望能有一站式的多论文综合结论、技术架构指标权衡（Trade-offs）以及支持把生成的高质量闪卡导出到专业记忆工具（如 Anki）中日常复习。”
   - *迭代改进*：新增 `Research Synthesis` 跨文献 AI 综合学术综述（含高层结论、可点击引用徽标 `[PAPER-ID:§Section]`、关键架构权衡对比与开放研究课题）；引入 3D 翻转卡片交互并支持一键导出标准 Anki `.tsv` 制表符格式；新增交互式概念拓扑图谱与 5 篇经典文献一键填入预设。
5. **公开站点可用性**：
   - *迭代改进*：上线地址 <https://scholar-pulse-noif6uwyn35.qoder.zone> 可见范围已设为「任何人都可访问」，无痕窗口无需登录即可完整体验检索、简报装配、AI 综述、拓扑图谱与薄弱点置顶流程。
